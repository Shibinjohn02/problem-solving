## 🧠 Sliding Window Mental Model (IMPORTANT)

Every Sliding Window problem answers only 3 questions:

1. What am I tracking?
   (sum / count / frequency / distinct chars)

2. When is window invalid?
   (condition breaks)

3. How do I restore validity?
   (shrink from left)

If you answer these → solution appears.


ONE PROPER TAKEAWAY (for (right - left + 1) type questions):

When the window is valid and the constraint is monotonic (only gets worse when expanding), then every subarray ending at right and starting anywhere from left to right is valid.


Sliding window relies on monotonicity:

Expanding window → sum increases or stays same
Shrinking window → sum decreases or stays same

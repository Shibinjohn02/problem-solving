🧠 One Mental Switch to Remember

Sliding Window asks:
“Can I shrink?”

Prefix Sum asks:
“What happened BEFORE?”

If shrinking is not possible → think prefix.


Sliding Window / Two Pointer

“I move pointers and maintain a window.”

Prefix Sum

“I precompute history so I can answer range questions instantly.”

Prefix sum problems are about range contribution, not motion.

| -------------- | ------------------------------------------------ |
| Two Pointer    | Can I adjust boundaries dynamically?             |
| Sliding Window | What makes a window valid/invalid?               |
| Prefix Sum     | Can I precompute history to avoid recomputation? |

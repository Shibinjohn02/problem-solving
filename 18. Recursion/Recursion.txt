Iske 3 important principles hain:
1. Base Case: Kab recursion ko stop karna hai?
2. Recursive Case: Problem ko chhota karke khud ko dobara call kaise karna hai?
3. Trust the Recursive Call: Assume karo ki chhoti problem ka answer recursive call correctly de dega. Tumhe bas us answer ka use karke current problem solve karni hai.



Recursion identify kaise karein?
Kisi problem ko padhte waqt yeh 3 questions khud se poochho:
1. Kya main original problem ko same type ke chhote subproblems mein divide kar sakta hoon?
2. Kya har subproblem ka answer, uske smaller subproblems ke answers se ban sakta hai?
3. Kya koi clear base case hai jahan answer directly mil jaata hai?

Note: "Kya mai is problem ka smaller version solve karke current problem solve kar sakta hoon?"

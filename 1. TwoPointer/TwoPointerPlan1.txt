| Strategy | Description | Movement | Example Use Case |
| 1. Converging Pointers | Pointers start at opposite ends of the data structure. | They move inward toward each other until they meet or cross. | Checking if a string is a palindrome. |
| 2. Parallel Pointers | Both pointers start at the same end (usually the beginning). | They move in the same direction. | Sliding Window Technique. The right pointer explores new information, while the left pointer tracks progress or maintains constraints. |
| 3. Trigger-Based Pointers | The first pointer moves independently until a condition is met (the "trigger"). | After the condition is met, the second pointer begins traversing to find related information. | Finding the $n^{th}$ node from the end of a linked list. |

Two Pointers
├── Converging (Opposite Direction)
│   ├── Meet-in-the-Middle (Two Sum II, Container With Most Water)
│   └── Palindrome / Symmetric Check
│
└── Parallel (Same Direction)
    ├── Sliding Window (Variable / Trigger-Based)

    ├── Fixed Window
    │   └── Window size = k, max/min sum/average
    ├── Fast–Slow Pointers
    │   └── Cycle detection, remove duplicates

    └── Multi-pointer / K-pointer
